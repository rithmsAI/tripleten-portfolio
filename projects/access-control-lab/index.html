Container and application controls

Non-root UID, read-only root filesystem, dropped capabilities, no-new-privileges, bounded process/memory/CPU resources and mounted local credentials. Event creation and its audit record commit together; forced audit failure rolls the event back.

Validation and limits

16 HTTP/configuration tests cover authorization, input rejection, audit records, persistence and rollback. Container execution is checked separately by GitHub Actions; see the current workflow status.

Local learning exercise related to Security+ topics, not a certification or security audit. Standard-library HTTP, no TLS or rate limiting, no production deployment. Compose state is ephemeral and network egress is not blocked.
